# Frontend

The Eldrev Next.js application will live here. It should consume a pinned version of the generated catalog TypeScript client published from `services/catalog-api/catalog-service-spec`.

A Dockerfile is included for when the Next.js app is initialized. It expects `package.json`, `package-lock.json`, and a `build` and `start` npm script.
